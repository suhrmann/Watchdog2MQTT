# Watchdog2MQTT
File Watchdog to MQTT transmits new or changed files via MQTT.

Watchdog2MQTT is built on [Watchdog](https://pythonhosted.org/watchdog/) to monitor file system events and 
[Eclipse Paho MQTT Python Client](https://eclipse.dev/paho/files/paho.mqtt.python/html/index.html) to transmit the data.
